# Security

RoastMyAudio is an experimental source preview. No supported binary release or formal security response SLA is established. The Flask workspace has no login and must run on loopback, for one user. Same-origin/Host checks reduce browser access risks but do not make it a hosted service.

For sensitive reports, use [GitHub private vulnerability reporting](https://github.com/heyaaakash/roastmyaudio/security/advisories/new) **only if the repository offers it**. The GitHub API reported it disabled during preparation on 2026-10-01. Enabling a working private route is an open launch gate. While unavailable, open an issue asking the maintainer for a private contact route without including the vulnerability, secrets, or affected personal data. Do not post exploit details, audio, transcripts, or credentials publicly.

Include the commit/version, affected workflow, prerequisites, impact, and a fictional reproduction in the private report. The maintainer must establish and verify a working private route before a public release.
