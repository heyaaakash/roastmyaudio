# Changelog

`VERSION` is authoritative. Entries describe source changes, not proof of published releases.

## 0.2.0 — prepared 2026-10-01, unreleased source preview

- Unified macOS capture controller for workspace/menu/shortcuts, guided permission/model/practice setup, durable Application Support storage, saved-audio recovery, target checks and clipboard restoration.
- Added microphone/shortcut controls, explicit login item settings, correction pairs, whole-phrase snippets, app styles, content-free diagnostics, and manual release checking.
- Added an ad-hoc local Mac app bundle recipe, icon, provenance/ZIP inspection, and packaged Cocoa/WebKit/model smokes; Developer ID signing and notarization remain open.
- Rebuilt the web workspace around recording, transcripts, vocabulary, scratchpad, and preferences with a distinct warm/violet identity.
- Added light/dark appearance, responsive layouts, reactive voice visualization, reduced-motion support, shortcuts, dialogs, recovery, export, and explicit sample data.
- Removed fake quotas, paid-plan UI, invented stats, and placeholder meeting/snippet screens.
- Preserved meaningful pronouns/articles in the hallucination filter instead of treating everyday words as noise.
- Fixed browser audio decoding, saved playback/re-transcription audio, temporary file cleanup, and language/cleanup preference handling.
- Added loopback/same-origin boundaries, upload limits, validated settings, atomic JSON writes, shared file locks, and stable legacy history IDs.
- Fixed native HUD annotation import without PyObjC and a removed Hugging Face download argument; bounded PyAV compatibility.
- Replaced stale setup/release claims with source-preview documentation, real screenshots, launch records, and local verification/source packaging scripts.
- Removed the GitHub Actions workflow. Existing remote Actions settings are disabled.
- Preserved earlier runtime files locally in ignored `data/legacy-runtime/` and removed them from source inputs. Earlier Git history still needs owner review/remediation.
